# Contributing to Kronos Community Lab

Thanks for contributing.

This repo is for learning how open-source collaboration works using Git and GitHub.

---

## 1. Before You Start

- Fork this repository
- Clone your fork locally
- Create a new branch before making changes

---

## 2. Basic Workflow

```bash
git clone <your-fork-url>

git checkout -b feature/your-change

git add .
git commit -m "feat: describe your change"

git push origin feature/your-change
```

Then open a Pull Request on GitHub.

---

## 3. Branch Naming Rules

Keep it simple:

- `feature/add-name`
- `fix/typo-readme`
- `task/update-contributors`

---

## 4. Commit Message Rules

Good:
- `feat: add contributor name`
- `fix: correct typo in README`
- `docs: update contribution steps`

Bad:
- `updated`
- `fix stuff`
- `changes`

---

## 5. Pull Request Rules

- One PR = one change
- Keep PRs small
- Explain what you changed
- Be open to feedback

---

## 6. What You Can Work On

Check the `tasks/` folder or Issues tab:

- Add your name to contributors list
- Fix a typo
- Improve documentation
- Simulate a merge conflict task

---

## 7. Important Rule

Don’t overthink it.

This repo is for learning Git workflows, not writing perfect code.
