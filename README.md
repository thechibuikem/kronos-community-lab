# Kronos Community Lab

Welcome to the Kronos Community Lab.

This repository is designed to help beginner contributors learn:

- Git fundamentals
- GitHub workflows
- Forking repositories
- Creating branches
- Opening Pull Requests
- Resolving merge conflicts
- Writing clean commits

## Contribution Workflow

1. Fork the repository
2. Clone your fork
3. Create a new branch
4. Make your changes
5. Commit your changes
6. Push your branch
7. Open a Pull Request

## Example Commands

```bash
git clone <your-fork-url>

git checkout -b feature/add-your-name

git add .
git commit -m "feat: add contributor name"

git push origin feature/add-your-name
```

## Beginner Tasks

Check the Issues tab for beginner-friendly contribution tasks.

## Rules

- Keep Pull Requests small
- One PR = One concern
- Write meaningful commit messages
- Be respectful during reviews

Happy contributing.
